# TABIRAÍCES

Sitio web + cotizador para Tabiraices — venta de materiales de construcción e inmobiliaria en Ventanilla, Colotepec, Puerto Escondido, Oaxaca.

## Servicios

- **Venta de materiales**: Bloques, tabiconas, postes para cercar
- **Retroexcavadora**: Servicio de excavación y movimiento de tierra
- **Inmobiliaria**: Venta y asesoría de terrenos

## Tech Stack

HTML multipágina + Tailwind CSS + JavaScript vanilla. Front en Cloudflare Pages.

## Estructura

- `index.html` — Página principal
- `productos.html` — Catálogo de productos
- `inmobiliaria.html` — Área inmobiliaria
- `contacto.html` — Formulario de contacto
- `app/` — Cotizador integrado
- `assets/css/styles.css` — Tailwind compilado
- `assets/js/site.js` — Lógica del sitio
